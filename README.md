# Escritorio Android Estilo Windows 11

Una aplicación Android nativa en Kotlin que emula un entorno de escritorio similar a Windows 11 para Android 13+.

## Características

- 🖥️ Menú de inicio con cuadrícula de aplicaciones
- 📋 Barra de tareas con aplicaciones abiertas
- 📁 Explorador de archivos
- 💻 Terminal integrada
- 🐍 Soporte para Python
- 🌐 Navegador integrado
- 🪟 Ventanas múltiples (arrastrable, redimensionable)
- ⚙️ Panel de configuración
- 🤖 Asistente IA integrado
- 📦 Instalador de aplicaciones

## Compilación

```bash
./gradlew assembleDebug
```
